# Akhil Ranjan — Investigative Journalism Platform

A premium editorial website for Akhil Ranjan, built as a polished static experience with expanded publishing sections for research, blog, gallery, testimonials, newsletter, and contact.

## Structure
- index.html — homepage and all core sections
- article.html — long-form article detail page
- author.html — author profile page
- styles.css — premium visual system and responsive behavior
- script.js — interactions, carousel, gallery lightbox, and form handling
- manifest.webmanifest — PWA manifest
- sw.js — service worker
- vercel.json — Vercel deployment config
- sitemap.xml / robots.txt / og-image.svg — SEO and social assets

## Deployment
1. Push this folder to GitHub.
2. Import the repository into Vercel.
3. Use the root folder as the project root.
4. Deploy.

## Notes
- The experience is designed for fast static hosting and can be extended with a real CMS later.
- The current build is fully local-file friendly and ready for static deployment.
